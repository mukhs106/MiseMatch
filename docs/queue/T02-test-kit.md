# T02: Usability test kit for the next question

**Goal:** Make the next round of testing quick to run on the current build.

**Read first:** the "Next question to test" in the October 22 decision log entry in docs/product-context.md.

**Scope:**
- Create `docs/testing/round-2.md` with: the research question; one realistic task ("You want to make chana masala for 2 tonight, but you have no fresh tomatoes"); a short facilitator script; four observable success measures (finds the swap unaided, states one consequence before applying, identifies what changed in the recipe afterward, predicts what the grocery list will contain); a one-to-five confidence question; and an empty results table for five participants.
- Confirm the demo reset returns the app to a clean starting state for each participant. If it does not, fix only that.

**Out of scope:** new features, analytics, recording tools.

**Done when:**
- round-2.md exists and fits on about one printed page
- Demo reset verified between two simulated sessions
- Committed and pushed
